A one-line cat joke for the make.fun bounty [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

The program writes a single line to `/output/entry.txt`:

> My cat wrote a will. I'm not in it. The dog is — and the dog's been dead for three years.

The joke lands in three beats: the cat has a will, the owner is cut out of it, and the sole heir — the dog — has been dead for three years.

Run with Node 22: `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to choose the output directory).
